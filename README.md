# Hearth games

Development builds of games made with Hearth, a small engine for dollhouse life simulations, played in the browser.

**Play:** https://trotor.github.io/hearth-web/

- *Very Good, sir!*: you are the butler of an English country house in 1910.
- *Mane Street*: a riding stable (coming later).

This repository holds only the built site. It is not open source: all rights reserved (see `LICENSE`).
Everything may still change, and saves are kept in your browser only.
